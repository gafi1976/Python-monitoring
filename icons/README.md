# Иконки устройств

Поместите PNG-файлы иконок в эту папку.

## Рекомендуемый размер
- **48×48** или **64×64** пикселей
- Формат: **PNG** (желательно с прозрачным фоном)

## Как использовать
1. Откройте настройки устройства (двойной клик или ПКМ → Настройки)
2. На вкладке **📋 Общие** нажмите **📂 Обзор…** рядом с полем «Иконка PNG»
3. Выберите PNG-файл из этой папки или любого другого места
4. Нажмите **Сохранить** — иконка отобразится на карте вместо эмодзи

## Рекомендуемые источники иконок
- https://www.flaticon.com/ (поиск: router, switch, server, firewall)
- https://icons8.com/icons/set/network
- Zabbix официальные иконки: https://www.zabbix.com/documentation/current/en/manual/config/visualisation/maps/map#map-elements
